WorkPalace
Descripción del Proyecto
WorkPalace es una plataforma digital desarrollada para conectar propietarios de espacios especializados infrautilizados con profesionales independientes, emprendedores y creativos que requieren estos espacios de manera temporal en la ciudad de Medellín.
El sistema permite el alquiler por horas, medias jornadas o días completos, optimizando el uso de infraestructura productiva y facilitando el acceso a equipamiento técnico de alto costo sin necesidad de inversión permanente.
Este proyecto ha sido desarrollado utilizando TypeScript, React y Node.js, implementando una arquitectura moderna basada en tecnologías web de alto rendimiento.
Tecnologías Utilizadas
El proyecto está construido con el siguiente stack tecnológico:
TypeScript: Lenguaje principal tanto en frontend como en backend, permitiendo tipado estático y mayor mantenibilidad del código.
React: Biblioteca para la construcción de la interfaz de usuario, basada en componentes reutilizables y manejo eficiente del estado.
Node.js: Entorno de ejecución para el backend, encargado de la lógica de negocio, gestión de reservas y comunicación con la base de datos.
Esta combinación permite una arquitectura full-stack en JavaScript/TypeScript, favoreciendo escalabilidad, mantenibilidad y coherencia en el desarrollo.
Misión
Conectar a profesionales independientes y emprendedores con espacios especializados que necesitan para trabajar, aprovechando lugares que permanecen vacíos gran parte del tiempo. Se busca facilitar el acceso de manera flexible, segura y accesible, impulsando el talento y el emprendimiento en Medellín.
Problemática
En Medellín existe una población significativa de trabajadores independientes que requieren espacios especializados como estudios de grabación, cocinas industriales, talleres o estudios fotográficos. Sin embargo, estos espacios implican altos costos de adquisición, mantenimiento o alquiler tradicional.
Al mismo tiempo, muchos espacios permanecen infrautilizados durante determinados horarios, generando pérdidas económicas. Esto evidencia la necesidad de una solución tecnológica que optimice el uso de estos recursos.
Solución Propuesta
Desarrollar una plataforma web que actúe como intermediaria entre propietarios y usuarios, permitiendo:
Publicación y gestión de espacios disponibles.
Búsqueda filtrada por tipo de espacio y ubicación.
Reserva por bloques de tiempo.
Sistema de pagos integrado.
Comunicación interna entre arrendador y arrendatario.
Historial de reservas y sistema de reseñas.
Público Objetivo
Profesionales independientes, emprendedores y creativos que necesiten espacios especializados de forma temporal en Medellín, sin un rango fijo de edad o nivel socioeconómico.
Competencia
No se identificó competencia directa con un modelo integral similar en la ciudad. Existen empresas que alquilan espacios específicos, lo cual abre posibilidades de alianzas estratégicas.
