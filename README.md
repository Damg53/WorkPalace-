WorkPalace
1. Introducción
WorkPalace es una plataforma digital desarrollada para conectar propietarios de espacios especializados infrautilizados con profesionales independientes, emprendedores y creativos que requieren estos espacios de manera temporal en la ciudad de Medellín.
La plataforma permite el alquiler por horas, medias jornadas o días completos, optimizando el uso de infraestructura productiva y facilitando el acceso a equipamiento técnico de alto costo sin necesidad de realizar grandes inversiones.
2. Justificación del Proyecto
En Medellín existe una población significativa de trabajadores independientes que necesitan espacios especializados como estudios de grabación, cocinas industriales, talleres de carpintería o estudios fotográficos. Sin embargo, estos espacios suelen implicar altos costos de adquisición, mantenimiento o alquiler tradicional.
Al mismo tiempo, muchos de estos lugares permanecen infrautilizados durante determinados horarios, generando pérdidas económicas para sus propietarios. Esta situación evidencia la necesidad de una solución tecnológica que optimice el uso de estos recursos y facilite el acceso temporal a infraestructura productiva.
3. Objetivos
3.1 Objetivo General
Desarrollar una plataforma web que facilite el alquiler temporal de espacios especializados en Medellín, promoviendo el emprendimiento y el aprovechamiento de recursos infrautilizados.
3.2 Objetivos Específicos
Permitir la publicación y gestión de espacios por parte de los propietarios.
Facilitar la búsqueda y reserva de espacios por parte de los usuarios.
Implementar un sistema seguro de gestión de reservas y pagos.
Garantizar trazabilidad y confianza mediante un sistema de reseñas.
4. Solución Propuesta
WorkPalace actúa como intermediario digital entre arrendadores y arrendatarios, ofreciendo:
Registro y autenticación de usuarios.
Publicación detallada de espacios.
Búsqueda filtrada por tipo de espacio y ubicación.
Calendario con disponibilidad en tiempo real.
Reserva por bloques de tiempo.
Sistema de pagos integrado.
Comunicación interna entre las partes.
Historial de reservas y calificaciones.
5. Tecnologías Utilizadas
El proyecto está desarrollado bajo una arquitectura full-stack utilizando tecnologías modernas:
5.1 Frontend
React
TypeScript
La interfaz está construida con React, utilizando TypeScript para garantizar tipado estático y mayor mantenibilidad del código.
5.2 Backend
Node.js
TypeScript
El servidor está desarrollado en Node.js, también utilizando TypeScript, permitiendo una arquitectura coherente entre cliente y servidor.
6. Público Objetivo
El público objetivo está conformado por profesionales independientes, emprendedores y creativos que necesiten espacios especializados de forma temporal en Medellín. El perfil demográfico es variable y no se limita a un rango específico de edad o nivel socioeconómico.
7. Competencia
No se identificó competencia directa con un modelo integral similar en la ciudad. Existen empresas que alquilan espacios específicos, lo cual representa posibles oportunidades de alianzas estratégicas.
