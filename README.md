## Estrategia de Branching

Para el proyecto WorkPalace se seleccionó GitHub Flow.

Esta estrategia se adapta al tamaño del equipo, compuesto por tres
integrantes, ya que permite trabajar mediante ramas de funcionalidades
de corta duración y posteriormente integrarlas a la rama principal
mediante Pull Requests.

También se considera adecuada por la frecuencia de despliegue esperada
del proyecto y porque simplifica el proceso de integración y revisión
del código al trabajar directamente con la rama main.
